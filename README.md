# QUẢN LÝ TÀI LIỆU THƯ VIỆN

## 1. Giới thiệu
Chương trình quản lý tài liệu thư viện được xây dựng bằng ngôn ngữ Java, áp dụng các kiến thức lập trình hướng đối tượng (OOP).

## 2. Các loại tài liệu
- **Sách:** Mã tài liệu, tên nhà xuất bản, số bản phát hành, tên tác giả, số trang.
- **Tạp chí:** Mã tài liệu, tên nhà xuất bản, số bản phát hành, số phát hành, tháng phát hành.
- **Báo:** Mã tài liệu, tên nhà xuất bản, số bản phát hành, ngày phát hành.

## 3. Chức năng
- Thêm mới sách, tạp chí và báo.
- Xóa tài liệu theo mã tài liệu.
- Hiển thị danh sách tài liệu.
- Tìm kiếm tài liệu theo loại.
- Thoát chương trình.

## 4. Kiến thức áp dụng
- Lớp và đối tượng.
- Tính kế thừa.
- Tính đóng gói.
- Tính đa hình.
- Lớp trừu tượng.
- ArrayList để lưu trữ danh sách tài liệu.

## 5. Công nghệ
- Ngôn ngữ: Java.
- Phiên bản: Java 21.
- Công cụ lập trình: Visual Studio Code.
